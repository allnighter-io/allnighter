Today those subscriptions don't know about each other. You work in one, and when you want a second opinion you open another window, paste the context in by hand, and paste the answer back. When one hits its limit, you stop — while the others sit idle with room you've already paid for.

A well-known hack wires exactly one pair together: Codex inside Claude Code. This page is the general case.

Then you just ask

No new tool to learn. You talk to the CLI you already talk to.

Once taught, your agent knows when to reach for the bench. These are real asks and exactly what happens — the command underneath is what your agent runs, not something you have to type.

Get a second opinion from GPT on this diff.
Your agent hands the diff to a Codex seat and brings the answer back into your session. You never leave the window.
alln run "…" --model model_gpt_sol
Have a team hunt this bug.
Bug Hunt: 5 models from different vendors read the repo in parallel and return one packet with their findings side by side. Read-only.
alln run "…" --team code_bug_hunt
Security-review this branch before I merge.
8 seats, 8 angles, one report. Nothing writes to your repo.
alln run "…" --team code_security_review
You review — let another model do the typing.
Your CLI keeps the reviewer's seat; a different model builds. Exactly one worker may edit files, under a per-repo write lock.
alln loop start "…" --pm caller

The write rule: research teams are parallel and read-only. Mutation is always a single worker per repo, locked. Ten models can advise you at once; only one can ever touch your files.

The part a hand-rolled setup can't do

It knows which subscription still has room.

alln capacity reads each vendor's real weekly and 5-hour headroom. So when your agent reaches for another model, it doesn't reach blindly — it can take the seat with quota to spare and leave alone the limit you're about to hit.

Every week, allowance you paid for expires unused on the subscriptions you didn't open. This is how it gets spent.
