Compact status or metadata label — plan tiers, counts, categories, model tags.

```jsx
<Badge tone="accent">Pro</Badge>
<Badge tone="positive" dot>Healthy</Badge>
<Badge tone="neutral" mono>1,284 tok</Badge>
```

Tones: `neutral` · `accent` (amber) · `positive` · `danger` · `info` · `warning`. `dot` adds a leading status dot; `mono` switches to the mono face for numbers/IDs.
