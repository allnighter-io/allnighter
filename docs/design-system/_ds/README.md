# `_ds/` — generic ikiro template snapshot (reference only)

This folder is a **generic ikiro design-system export** (`IkiroDesignSystem_…`),
not the Allnighter bundle. It was carried over from the old `design-system2/`
drop on request ("we might need them"). Its manifest lists template components
(Avatar, Tag, LinkRow, Stat) that are **not** part of Allnighter.

The authoritative Allnighter generated bundle lives at the design-system root:
`_ds_manifest.json`, `_ds_bundle.js`, `_adherence.oxlintrc.json`
(namespace `AllnighterDesignSystem_…`). Use those, not this folder.
