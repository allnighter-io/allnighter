## What the two failures bought

The gate found a real half-implementation of §4.3 step 7 that unit tests had
missed: the plist was restored and the prior job re-bootstrapped, but the
**binary was not**, leaving the candidate in place with the correct bytes sitting
unused in `.rollback`. Fixed in `8f9637c0` by giving `CanonicalCLIInstall` sole
ownership of the restore — binary, then symlink, then plist, before any
re-bootstrap.

It also found a proof that could not fail. The update scenario asserted "build
identity changed" via cdhash, but `rebuild_cli.sh` regenerates a build timestamp
so the cdhash moves on every rebuild regardless of source. That assertion now
compares git sha and reports honestly:

```text
update: same-version reinstall — repo HEAD unchanged at 8f9637c0…
PASS — update: same-version reinstall (not a vA -> vB proof)
```

A run that is not a vA → vB proof now says so instead of passing as one.

## Injection seam

`ALLNIGHTER_SERVE_TEST_INJECT=bootstrap-failure`, added by ASR-S06d:

- gated on the exact literal — presence or any other value injects nothing;
- announces itself on stderr on every attempt;
- fires only at the install/converge bootstrap, never the restore bootstrap;
- scrubbed from the spawn environment, with a test proving a child cannot
  inherit it — a daemon that did would fail to bootstrap forever;
- inert during a normal `rebuild_cli.sh`: no warning, host healthy.

## What this does NOT prove

- One host, ad-hoc signing track, one update lineage.
- `SERVE_BUSY` (§5.3, exit 75 — update refused while obligations are active) is
  untested; the update path was only exercised from an idle healthy host.
- `SERVE_ROLLBACK_FAILED` — the path where the *binary restore itself* fails —
  has unit coverage only. Inducing it on a host would require a second injection
  point and was not built.
- The rollback was proven against an injected failure, not a naturally occurring
  one. That is what §8 asks for, but it is not the same as the real EIO case
  ASR-S02f fixed.
- §10.1 R1 is untouched and stays open.
