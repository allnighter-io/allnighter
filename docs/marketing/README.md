## Core Message

You already pay for the AI team. Allnighter makes it show up to work.

Allnighter is the local Mac + iPhone control loop for the AI coding CLIs a solo
builder already uses: Claude Code, Grok, Codex, Gemini, Aider, Cursor, and future
workers. It does not sell model access. It coordinates the subscriptions and
local tools the user already has.

## Claim Discipline

Use these claims:

- "Allnighter runs your own local CLI tools."
- "Use your own Claude Code, Grok, Codex, Gemini, Aider, and local workers."
- "For eligible Claude subscribers, `claude -p` usage is covered by Anthropic's
  separate Agent SDK monthly credit after they claim it."
- "Claude Max 5x currently includes a $100/month Agent SDK credit."
- "Grok publicly markets higher limits and multi-agent on paid plans; exact
  limits can change."
- "Allnighter applies the team + plan writer pattern locally, inspired by the Fusion
  result that model teams can beat solo frontier calls."
- "OpenRouter reported specific DRACO deep-research benchmark lifts for Fusion;
  cite those numbers only as OpenRouter's benchmark, not as Allnighter's result."

Avoid these claims:

- "Allnighter gives you $100 of Claude."
- "Allnighter includes Claude/Grok/Codex usage."
- "Grok is unlimited" unless xAI publishes that exact promise.
- "Zero cost" without saying "zero marginal model cost when you use subscriptions
  you already pay for."
- "Beats frontier models" as an Allnighter performance claim before our own evals
  prove it.
- "Allnighter is X% better" before Allnighter has its own eval suite.
