# GUI Invariants

**Status:** Canonical / Always True
**Scope:** Rules that hold for every Allnighter UI surface, Mac and iOS. If a
task would break one, stop and escalate (Tier D in `GUI_Workflow.md`).

## Truth & State

1. **UI does not own domain truth.** Views bind to `AllnighterCore` models and
   the `@Observable` run store fed by the `RunEvent` stream. Views render and
   send intents; they never mutate run state, worker status, or answers.
2. **No GUI-only data.** Never fabricate fields, statuses, worker names, model
   labels, counts, or option lists in the view layer. If the value has no owner
   in the core contract, stop and raise the gap — do not invent it in SwiftUI.
3. **Derived values name their source.** A computed label states which model
   fields it derives from; formatting lives in a testable presenter, not inline.

## Honesty

4. **Never fake state.** A failed worker is shown `failed`; a timeout shows
   `timed_out`. No simulated progress, no optimistic "done" before the event.
5. **Numbers are concrete and mono.** Counts, elapsed times, model IDs, run
   slugs, and paths use the mono token; no rounded-up or placeholder figures.
6. **Hide the plumbing.** User-facing copy says panel / worker / council /
   master plan — never worktree / subprocess / branch / PID.

## Visual (binds to the design system)

7. **Dark mode only.** Build on `--bg-base`/`-surface`/`-raised`; never a light
   background.
8. **One warm signal.** Amber (`--accent`) is the single primary action, the
   live state, the synthesizer/winner, and the mark. Status hues stay muted; add
   no new accent colors. Full rules: `docs/design-system/production.md`.
9. **Voice:** calm, plain-spoken, sentence case, verbs first, no emoji, no hype.

## Completeness

10. **Every critical surface defines loading, empty, error, running, and done
    states.** A run view must handle `queued`/`running`/`done`/`failed`/
    `timed_out` and a global stop.
11. **Critical iOS flows must be usable one-handed** on a phone (the floor
    manager is a glance-and-tap surface).

## Safety

12. UI that starts/kills/routes runs, spends quota, or touches secrets, Keychain,
    or pairing is **Tier D** — it needs the owning contract and a surface brief
    before code. See `GUI_Workflow.md` §3.
