# Send To Team Mockups

Three static HTML variants for the Send to team surface:

- `variant-a-pm-recommended.html` - Project Manager recommendation first.
- `variant-b-team-map.html` - Browseable team map with family columns.
- `variant-c-composer-sheet.html` - Compact composer-attached sheet.

Open the files directly in a browser. They link the Allnighter design-system
tokens from `docs/design-system/styles.css`.

These are evaluation artifacts only. The production surface must use the Core
`TeamCard`/team-run contracts described in `../brief.md`.
